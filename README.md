The same files are attached to the [latest release](../../releases/latest) and listed on the download page, https://skuirrels.github.io/flowster-releases/

- **Windows:** the Setup .exe is recommended; the .msi suits managed installs. If SmartScreen warns, choose **More info → Run anyway**.
- **macOS:** Apple Silicon is for M1 and later Macs, Intel for older ones. Open the .dmg and drag Flowster to Applications. The first time, right-click Flowster and choose **Open** (the builds aren't notarized yet).
- **Linux:** the AppImage runs on any distribution; use the .deb on Debian/Ubuntu and the .rpm on Fedora/openSUSE.

Installed copies update themselves: Flowster checks for a newer version when it starts, and from Help ▸ Check for updates, and offers to install it.
